## LuigiSMP

<a href="https://luigismp.online"><img src="https://img.shields.io/badge/luigismp.online-website-ff9800?style=for-the-badge" alt="website" /></a>
<img src="https://img.shields.io/badge/Minecraft-1.21.11-c2185b?style=for-the-badge" alt="Minecraft 1.21.11" />
<img src="https://img.shields.io/badge/CZ%20%2F%20EN-bilingual-7b1fa2?style=for-the-badge" alt="Czech and English" />

A Czech survival server with one world that never resets, built and run by one person. You join with a plain vanilla client, there is nothing to install.

- **Chunk claims** with per-player trust and flags
- **Economy**: paid playtime, daily quests, an NPC buyer, public warps and death insurance
- **Tameable wildlife**: bears, crocodiles, rats, squirrels, ducks and crabs, some of them rideable
- **Custom items and blocks**: emerald gear, paged storage chests, an autoplacer, plushies
- Everything in **Czech and English**, switchable per player
**[luigismp.online](https://luigismp.online)** · [Player wiki](https://github.com/unknown-566/LuigiSMP-Wiki)

## LuigiScreen

<a href="https://github.com/unknown-566/LuigiScreen"><img src="https://img.shields.io/github/stars/unknown-566/LuigiScreen?style=for-the-badge&color=ff9800" alt="stars" /></a>
<img src="https://img.shields.io/badge/Paper-1.21.11-c2185b?style=for-the-badge" alt="Paper 1.21.11" />
<img src="https://img.shields.io/github/license/unknown-566/LuigiScreen?style=for-the-badge&color=7b1fa2" alt="license" />

A Paper plugin that plays live streams, videos, images and GIFs on walls made of Minecraft maps. Players need no mods, the server does the decoding.

- **RTMP and MJPEG** live streams straight from OBS, plus local videos, GIFs and images
- **Control Studio** in-game (`/screen menu`) and a **Web Studio** in the browser (`/screen web`)
- Playlists, schedules, event scenes, screen groups and audience voting
- Draft and publish editing with snapshots and undo
**[Get LuigiScreen](https://github.com/unknown-566/LuigiScreen)** · [Documentation](https://unknown-56-works.gitbook.io/luigiscreen/)
